# Flow with Mind v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A ten-effect shader stack driven by a grammar that maps the director's state to a program plus seven visual gestures; a Computer-music source via `getDisplayMedia`; a visible Immerse control.

**Architecture:** Two new pure modules — `engine/grammar.mjs` (program vector, `programFor`, `blendPrograms`, moods) and `engine/visual-gestures.mjs` (event-triggered envelopes) — feed a rewritten `engine/post.mjs` (one fragment shader, all effects as uniforms). `app.mjs` builds the state each frame, blends toward the target program (continuous over ~2 s, discrete on phrase boundaries), layers the active gesture and renders. `audio.mjs` gains a system/tab audio source. JEV gets one `mood` question end to end.

**Tech Stack:** as v2 (vanilla ES modules, vendored Three.js r180, Web Audio, node:test, stdlib Python).

**Spec:** `docs/superpowers/specs/2026-10-25-flow-v3-visual-language-design.md` (binding; v1/v2 apply where silent).

### Task 1: Grammar

**Files:** Create `immersive/engine/grammar.mjs`; Test `tests/grammar.test.mjs`

**Interfaces:**
```js
export const FORM_KINDS = ['tunnel','spiral','cobweb','lattice'];
export const MIRRORS = ['none','h','v','quad'];
export const MOODS = ['clear','dream','melt','electric','holy'];
export const CONTINUOUS = ['echoDecay','echoZoom','echoSpin','droste','tunnel','tunnelSpeed','formDensity','formDrift','formContrast','warp','warpScale','warpRate','breath','contour','contourLine','chromaSplit','chromaCycle','gain'];
export const DISCRETE = ['fold','mirror','formKind'];
export function defaultProgram() → Program   // fold 0, mirror 'none', formKind 'tunnel', all continuous 0 except warpScale .5, warpRate .3, contourLine .5, gain .6
export function programFor(state, depth, into = defaultProgram()) → Program
//   state = { I, A, E, C, H, L, heat, ship:'hover'|'ship', diving, jump, calm }
export function blendPrograms(a, b, u, into = defaultProgram()) → Program   // continuous lerp; discrete from b when u ≥ 0.5
export function applyMood(program, mood, amount) → program   // adds the mood bias × amount, clamped
```
Mapping (from the spec §4.1, with these numbers): `d = clamp01(depth)`, `lead = (I+1)/2`, `leading = lead > 0.5`, `foldCap = FOLDS[round(d·4)]`.
- `formKind`: leading ? (C > 0.5 ? 'spiral' : 'tunnel') : (A > 0.3 ? 'cobweb' : 'lattice'); jump → 'lattice'.
- `formDrift`: leading ? +(0.3 + 0.7·C) : −(0.2 + 0.3·(1 − C)); dive ×2.5 clamped; jump 1.
- `formDensity = clamp01(0.3 + 0.6·E)·d·(1 − 0.5·A)`; `formContrast = min(0.6, 0.6·d)`.
- `fold = leading ? foldCap : 0`; `mirror = leading ? 'none' : (A > 0.5 ? 'h' : 'quad')`; jump → mirror 'quad'.
- `warp = min(d, (leading ? 0.2 + 0.5·H : 0.2 + 0.6·A + 0.3·H) + 0.5·heat)`, floor 0.1 → when d < 0.1 warp ≤ 0.1; `warpScale 0.5`, `warpRate 0.2 + 0.4·E`.
- `contour = 0.8·(1 − H)·d`, `contourLine 0.5`.
- `echoDecay = min(1, 0.5 + 0.4·H + 0.3·heat)`, `echoZoom = 0.3 + 0.4·lead`, `echoSpin = 0.5·lead`, `droste = L < 0.3 ? (0.3 − L)/0.3 : 0`.
- `breath = C < 0.5 ? 1.2·(0.5 − C) : 0`.
- `chromaSplit = calm ? 0 : 0.3·H·d` (jump 0.6·d), `chromaCycle = 0.2 + 0.3·E`.
- `tunnel = ship === 'hover' ? 0 : diving ? 0.7 : 0.3` (jump 1); `tunnelSpeed = diving ? 1 : 0.4`.
- `gain = calm ? min(0.5, 0.3 + 0.7·d) : 0.3 + 0.7·d`.
Moods (bias added × amount): clear {contour +.3, warp −.2, chromaSplit −.2}, dream {breath +.3, echoDecay +.2, warp +.1}, melt {warp +.4, echoDecay +.3}, electric {chromaSplit +.3, formDensity +.2, chromaCycle +.3}, holy {fold → 8 when amount ≥ .5, formKind 'tunnel' when amount ≥ .5, gain +.1, contour +.2}.

### Task 2: Visual gestures

**Interfaces:**
```js
export const GESTURES = ['take','yield','listen','carry','surprise','rebirth','jump'];
export class VisualGestures {
  constructor({ hysteresis = 0.05, surpriseGap = 2 } = {})
  update(dt, state /* {I, A, surprise, beatSeconds} */, events /* {onset, rewind, jump} */) → { active: string|null, env: 0..1, overrides: object }
  // overrides: partial program, already scaled by env, e.g. take → {formKind:'spiral', formDrift:+1·env, fold:6}
  //   yield → {breath:.6·env, mirror:'h', formDensity:0}; listen → {warp: pulse·env} where pulse rises .4 per onset and decays over a beat
  //   carry → {tunnel:.4·env}; surprise → {chromaSplit:.8·env, contour:+.5·env (added, clamped by caller)}; rebirth → {droste: env}; jump → {chromaSplit:.6·env}
  // lengths: take 2 beats, yield 2, listen up to 4, carry 4, surprise 1, rebirth 2 s, jump 4 s
  // env: rises over the first 20 % of the length, falls to 0 at the end; a new trigger is ignored while one is active except rebirth/jump, which pre-empt
  // carry: fires after 16 beats of I > 0.2 with no gesture; the count resets on any gesture or when I ≤ 0.2
  // surprise: at most once per surpriseGap seconds
}
```

### Task 3: The shader stack

**Files:** Rewrite `immersive/engine/post.mjs`; keep `engine/feedback-math.mjs` as the echo reference.

**Interfaces:**
```js
export class PostFX {
  constructor(renderer, { width, height })
  setSize(w, h)
  render(scene, camera, program, { pulse = 0, beatPhase = 0, time = 0, dt = 1/60, quality = 1 })
  dispose()
}
```
One fragment shader, in this order on the sampling coordinate / colour: `warp` (iterated `uv += sin(uv.yx·k + t)/a`, 6 iterations × quality) → `tunnel` (log-polar remap mixed by amount; `tunnelSpeed` scrolls log r with time) → `fold` (as now) and `mirror` (h: |x−.5|, v: |y−.5|, quad: both) → sample scene → `contour` (luminance posterised into `2 + 10·contour` bands with dark iso-lines of width `contourLine`) → `forms` (log-polar stripes: `kind` sets the stripe direction — tunnel: along log r; spiral: 45°; cobweb: along θ; lattice: both multiplied; `density` sets frequency; `drift` moves the phase along log r with time and beatPhase; blended with `screen` at `contrast`) → `echo` (prev frame sampled with zoom/spin; `droste` mixes a log-polar spiral sample of prev; mix `1 − exp(−(cur·gain + prev·min(decay, .96)))`) → `breath` (barrel factor `1 + 0.08·breath·sin(2π·beatPhase)` applied to the initial uv) → `chroma` (sample R and B offset by `split·8 px` along the radius; hue rotate by `chromaCycle·time`). Fold cross-fade kept from v2. The scene target and ping-pong feedback targets stay.
