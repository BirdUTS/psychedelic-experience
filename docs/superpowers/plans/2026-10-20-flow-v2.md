**Tech Stack:** as v1 (vanilla ES modules, vendored Three.js r180, Web Audio, node:test on Node 24, stdlib Python server). No new dependencies.


```js
export class SnapshotRing {
  constructor(arrays /* from sim.state() */, { keep = 4 } = {})   // preallocates keep × copies
  capture(L, time)             // copies the live arrays into the next slot with its liveliness and time
  best() → { index, L, time } | null
  count
  rewindTo(index, { seconds = 2 } = {})     // starts a dissolve from the live arrays toward slot `index`
  update(dt, live, { discrete = [], random = Math.random })  → progress 0..1
  //   continuous arrays lerp live := from + (to − from)·u; arrays listed in `discrete` (by position in state()) switch per element
  //   at a random moment in [0, seconds]; u is monotonic; when progress reaches 1 the dissolve ends and live equals the snapshot
  dissolving → boolean
}
```
